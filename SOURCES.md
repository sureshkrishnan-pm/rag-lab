# Corpus sources

The demo corpus (`src/data/corpus.ts`) is 10 short, original paragraphs on
space exploration topics (Apollo, the ISS, Voyager, Mars rovers, Hubble,
JWST, reusable rockets, satellite navigation, exoplanets, and space
weather), written from scratch for this project — not copied or adapted
from any external source. Facts are general public knowledge; no
attribution is required, but none is owed to a specific source either.

The embedding model, [Xenova/all-MiniLM-L6-v2](https://huggingface.co/Xenova/all-MiniLM-L6-v2),
is loaded at runtime from a CDN under its own license (see the model card).
